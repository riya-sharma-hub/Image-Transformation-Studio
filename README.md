
# Image Transformation Studio

A Python-based Computer Vision application that allows users to apply different image transformation and processing techniques through an interactive interface.

## Overview

Image Transformation Studio is designed to demonstrate fundamental image processing and computer vision operations in an easy-to-use application.

The project provides multiple image transformation techniques that allow users to upload an image, apply transformations, and visualize the processed output.

## Features

- Image Upload
- Image Resizing
- Image Rotation
- Image Flipping
- Image Cropping
- Grayscale Conversion
- Edge Detection
- Image Enhancement
- Interactive Image Processing

## Technologies Used

- **Python**
- **OpenCV**
- **Streamlit**
- **NumPy**
- **Pillow**

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/riya-sharma-hub/Image-Transformation-Studio.git
```

### 2. Navigate to the Project Folder

```bash
cd Image-Transformation-Studio
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## Running the Application

Run the following command:

```bash
streamlit run app.py
```

The application will open in your browser at the local Streamlit address.

### Windows

You can also use the provided batch file:

```text
run_app.bat
```

to launch the application.

## How It Works

1. Upload an image through the application.
2. Select the desired image transformation or processing technique.
3. Adjust the available parameters if required.
4. Preview the transformed image.
5. Compare the original and processed images.
